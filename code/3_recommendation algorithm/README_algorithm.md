# 🧠 추천 알고리즘 개요

본 추천 알고리즘은 사용자의 **색상 점수**, **계절 점수**, **스타일 점수**를
각각 독립적인 점수로 계산한 뒤, 이를 합산하여 최종 향수 추천 순위를 산출한다.

모든 점수는 **각 100점 만점**, 최종 점수는 **300점 만점** 기준으로 계산된다.


## 📐 계산식

### - 기본 수식

$$Score = W_{color} \cdot \text{ColorScore} + W_{season} \cdot \text{SeasonScore} + W_{style} \cdot \text{StyleScore}$$

- 초기 설계에서는 세 점수를 **동일 비중 (1:1:1)** 으로 반영
- 이후 사용자 데이터 누적에 따라 가중치 자동 조정 구조로 확장


### - 상세 수식

$$Score = W_{color} \cdot \left[ 100 \times \left( 1 - \frac{\sqrt{(R_1 - R_2)^2 + (G_1 - G_2)^2 + (B_1 - B_2)^2}}{255\sqrt{3}} \right) \right]+ W_{season} \cdot \left[ 100 \times \frac{V_{selected}}{V_{total}} \right]+ W_{style} \cdot A_{ij}$$



## 📊 변수 정의

| 변수 | 설명 |
|---|---|
| $W_{color}, W_{season}, W_{style}$ | 색상, 계절, 스타일 점수의 반영 비중 |
| $R_1, G_1, B_1$ | 사용자 의류 이미지에서 추출한 RGB 색상 |
| $R_2, G_2, B_2$ | 향수 향조(Main Accord)의 대표 RGB 색상 |
| $V_{selected}$ | 사용자가 선택한 계절에 대한 향수 적합도 |
| $V_{total}$ | 해당 향수의 전체 계절 적합도 합 |
| $A_{ij}$ | 스타일 $i$ 와 향조 $j$ 간 적합도 계수 |


## 1️⃣ 색상 점수 (Color Score)

Color Score는 사용자 착장 색상과 향조 색상 간의
**시각적 유사도**를 기반으로 계산된다.

- 상의 RGB : 하의 RGB = **7 : 3**
- 원피스는 단일 RGB 벡터 사용
- 향조 색상은 Main Accord 1·2·3을 **6 : 3 : 1** 비율로 가중 평균

RGB 공간에서의 유클리디안 거리를 계산한 뒤,
최대 거리로 정규화하고 100점 만점으로 변환한다.

## 2️⃣ 계절 점수 (Season Score)

Season Score는 사용 계절과 향수의 계절 적합도 간의 일치 정도를 반영한다.

- 봄 / 여름 / 가을 / 겨울 중 1개 선택
- 향수별 계절 적합도 합으로 나누어 비율 계산
- 100점 만점 기준으로 점수화

이를 통해 같은 향수라도 계절에 따라
추천 우선순위가 달라지도록 설계했다


## 3️⃣ 스타일 점수 (Style Score, $A_{ij}$)
Style Score는 **모델 기반 스타일 분류 결과**와  
**설문 기반 스타일–향조 적합도 데이터**를 결합해 산출한다.

### - Style Score 구성
- 의류 이미지 → 스타일 분류 모델을 통해 사용자 스타일 $i$ 예측
- 설문조사 기반으로 스타일($i$)–향조($j$) 간 조화도 점수 매핑
- 예측된 스타일에 해당하는 향조 점수를 Style Score로 사용

### - 활용 근거
- *「향수의 이미지에 관한 연구 – 비주얼 광고 분석과 사용자의 반응을 중심으로」*
- 사용자 인식 데이터를 반영한 향–이미지 연관성 설계


## 🏆 최종 추천 결과 산출

- Color / Season / Style 점수를 합산해 최종 Score 계산
- Score 기준으로 **Top-3 향수 추천**
- 각 추천 결과는 색상·계절·스타일 기준 설명과 함께 제공



## ⚙️ 점수 안정화 및 성능 고도화

### - 문제점
- 특정 향조가 설문 점수로 상위권을 독점
- 스타일·색상·계절 점수 간 스케일 차이 존재

### - 개선 방식
- Re-Ranking 적용
- Min-Max Scaling + ε Smoothing
- 사용자 데이터 누적 기반 Precision@k 기준 가중치 자동 조정

이를 통해 추천 결과의 **안정성·다양성·정확도**를 함께 확보했다.
