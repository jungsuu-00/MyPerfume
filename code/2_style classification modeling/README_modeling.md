# 👗 스타일 분류 모델링

본 모델은 **스타일 라벨이 포함된 JSON 데이터**를 활용한  
**지도학습 분류 모델**이다.

상의·하의 조합(또는 원피스)을 입력으로 받아  
코디의 전체 분위기를 하나의 **스타일 레이블**로 예측하며,  
예측 결과는 향수 추천 알고리즘의 **스타일 점수 산출**에 활용된다.


## 🎯 모델링 목적

- JSON 라벨 기반 지도학습을 통한 스타일 자동 분류
- 주관적인 스타일 개념을 예측 가능한 분류 문제로 정의
- 추천 알고리즘에 활용 가능한 안정적인 스타일 결과 확보


## 🏷️ 분류 대상 스타일

다음 7개 스타일 클래스를 예측한다.

- 클래식 / 로맨틱 / 소피스트케이티드 / 섹시 / 스포티 / 젠더리스 / 아방가르드  


## 🧹 데이터 구성 및 전처리

- JSON 내 스타일 라벨을 정답값으로 활용
- 스타일 그룹별 최빈값 기반 결측치 보정
- 상의·하의 **색상 조합 / 핏 조합 파생 변수 생성**
- 범주형 변수 인코딩
- 클래스 불균형 완화를 위한 **class weight 적용**


## 🤖 모델 선정 및 학습

- **LightGBM**: 대규모 데이터 속도 및 고성능 확보  
- **CatBoost**: 범주형 변수 자동 처리, 과적합에 비교적 강건  

두 모델을 결합한 **앙상블 구조**를 최종 적용했다.

## 📊 성능 평가

성능 평가는 **F1-score** 기준으로 진행했다.

| 모델 | F1-score |
|---|---|
| LightGBM | 0.71 |
| CatBoost | 0.69 |
| Ensemble | 0.76 |

단일 정확도보다 **스타일 분류 안정성**을 중심으로 평가했다.

## 🔗 추천 알고리즘 내 역할

- 예측된 스타일 → 스타일 점수 산출
- 스타일–향조 적합도 매핑과 결합

본 모델은 라벨링된 데이터를 기반으로 학습된 지도학습 모델로서,  
추천 결과의 **일관성과 설명력**을 뒷받침하는 핵심 구성 요소다.
